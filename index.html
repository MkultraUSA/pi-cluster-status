pi-cluster — live security posture

A 4-node Raspberry Pi Kubernetes cluster that rebuilds and replaces its own images when CVE advisories make fixes available. Rendered 2026-11-04 18:39 UTC by the cluster itself.

How it works

Every 6 hours the cluster scans every image it runs (trivy, DB auto-refreshed from CVE feeds). A verdict engine marks images REBUILD+REPLACE DUE when upstream fixes exist. The actuator then rebuilds the image in-cluster with Debian security patches baked in, commits the new tag to git, and ArgoCD rolls the fleet behind readiness gates — with a timestamped evidence record for every action. Humans gate only the risky parts: k3s upgrades and major version bumps.
